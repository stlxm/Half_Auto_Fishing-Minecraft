# Minecraft 半自動釣り（Windows 11）

Minecraft Java版で手動ホットキーまたは任意で開始するPC再生音の照合を使い、選択したゲームウィンドウへ1回操作を送るGUIアプリです。音声の自動検出は初期状態でオフの試験的機能です。ゲーム内部のヒットイベントを直接取得するものではなく、誤検出・見逃し・入力遅延が起こり得ます。検知回避機能はありません。使用するサーバーのルールを確認してください。

## 1. ダウンロードと起動（Python不要）

1. このリポジトリの **Actions** タブを開く。
2. 左の **Windows EXE build** → 一番新しい成功済みの実行履歴を開く。
3. ページ下の **Artifacts** にある `HalfAutoFishing-Windows` をダウンロードする（GitHubへのログインが必要な場合があります）。
4. ZIPを展開して `HalfAutoFishing.exe` を取り出す。
5. EXEをダブルクリックして起動する。コマンドプロンプトは不要です。

※ **Actionsが成功するまではEXEをダウンロードできません。** Windows向けビルドはGitHub Actions上で行います。公開された実行ファイルを使う場合、出所を確認してから実行してください。SmartScreenが警告する場合があります。無条件で警告を回避せず、入手元とファイルを確認してください。

## 2. 初回設定と使い方

1. Minecraftを起動する。最初に自分のシングルプレイワールドで動作を確認する。
2. `HalfAutoFishing.exe` を起動し、操作キー（初期値F8）を設定します。入力欄に `f9` や `ctrl+shift+f9` のように入力するか、「キーを登録」を押して使いたいキー（同時押しも可）を押します。Escを押すとキー登録をキャンセルします。登録後は「保存して開始」を押します。キーを変えるときは先に停止してください。
3. 「操作内容」は通常「右クリックのみ」を選ぶ。Escを押すとMinecraftのメニューが開くため、「Esc → 右クリック」は独自UI等で必要な場合だけ選ぶ。「Esc → Esc → 右クリック」も選択できます。
4. 操作間隔（初期値120ms）と連続実行防止（初期値500ms）を必要に応じて指定する。
5. Minecraftを起動した状態で「操作するゲーム画面」の「再検索」を押し、一覧から**Minecraftのゲームウィンドウ**を選びます。ゲームタイトルにMinecraftが含まれていて候補が一つなら自動選択されます。候補が複数あるときやModで名前が変わる場合は手動で選んでください。Minecraft Launcherではなくゲーム本体を指定します。
6. 「操作キーで選択したウィンドウに切り替えてから操作する」をオンにします。「保存して開始」を押し、ブラウザが前面にある状態でF8を押して動作確認します。Windowsが切り替えを許可した場合に限り、選択ウィンドウを前面にして指定操作を1回実行します。
7. 終わったらアプリ画面で「停止」を押すか、アプリを閉じる。

キーの設定を変える場合は一度「停止」してから設定を変え、「保存して開始」を押してください。設定は `%APPDATA%\HalfAutoFishing\config.json` に保存され、次回起動時にも読み込まれます。

### 途中からF8が動かなくなる場合・診断方法

今回の更新では、操作キーを受信すると画面に「操作キーを受信しました（N回目）」と表示します。Minecraft側のウィンドウが同じプロセス内で作り直された場合は、唯一の候補だけを自動で再検出します。別のプロセス（ブラウザなど）を自動選択することはありません。

1. F8を押しても何も変わらない場合は、アプリの状態欄に「操作キーを受信しました」が出るか確認します。**受信表示がない場合**は「キー検知を再登録」を押し、再び試します。このボタンはアプリを再起動せずキー検知だけを登録し直します。
2. 受信表示があるがゲームに切り替わらない場合は、状態欄の「Windowsが画面の切り替えを許可しませんでした」などの理由を確認してください。ウィンドウモードで対象ゲームのタイトルを再確認し、「停止」→「再検索」→Minecraftを選択→「保存して開始」を試します。
3. Minecraftを一度終了・再起動した場合はプロセスIDも変わるため、別のアプリへ誤入力しないよう自動選択を行いません。再検索してゲームを選び直してください。
4. 反応しない状態が続くときは、症状と状態欄の文言を記録してください。Windowsの前面切り替え制限やキーボードフックの停止などが起きる環境では、ソフトの再起動が必要になる場合もあります。

### デュアルモニターでブラウジング中にF8を押す場合

1. Minecraftを先に起動しておき、半自動釣りアプリで「再検索」→Minecraftの**ゲーム画面**を選択します。一覧にはWindowsのタイトル付きウィンドウが表示されます。ゲーム名にMinecraftが含まれない場合でも、タイトルで手動選択できます。
2. 「操作内容」を **Esc → 右クリック** にし、「F8で選択したウィンドウに切り替えてから操作する」をオンにして「保存して開始」します。Escで通常のゲームメニューが開く場合、右クリックしても釣り竿は操作されないので、その場合は「右クリックのみ」など用途に合う操作内容に変更してください。
3. もう一方のモニターでブラウザを前面にし、F8を押してみてください。選択したウィンドウを前面にできたことを確認してからキー・マウス入力を送ります。右クリックの際は**選択したゲームの表示領域の中央へマウスカーソルが移動します**。デュアルモニターでブラウザ側にカーソルが残っていても、ゲーム画面内でクリックするためです。
4. Windowsがウィンドウ切替を拒否したときや、指定のゲーム画面が閉じたときは**ブラウザにEscや右クリックを送らず中断**します。ゲームを再起動した場合は「再検索」でウィンドウを選び直してください。

「ウィンドウ切替」をオフにした場合、選択したゲームがすでに前面のときだけ入力します。長時間のプレイ中にゲーム画面が再生成された場合は「停止」→「再検索」→ゲーム画面を再選択→「保存して開始」を行ってください。対象を選ばない状態では開始できません。設定したF8がブラウザなどの既存ショートカットと衝突するときは、操作キーを変更してください。

Windowsのアクティブウィンドウ切替にはOSによる制約があり、**すべてのPC・全画面モードでの成功を保証するものではありません**。ゲームをウィンドウモードまたはボーダーレスで動かして、まずシングルプレイで操作を確認してください。別のウィンドウを選択してしまうとそのウィンドウが操作対象になるため、選択したタイトルを確認してください。

## 3. 画像判定による操作の切り替え

操作内容で **「メニューならEsc→右クリック／通常時は右クリック」** を選択すると、選択中のMinecraftウィンドウのポーズメニューを画像で照合します。登録済みのメニューに一致したときだけEscでメニューを閉じ、その後に右クリックします。メニューに一致しない場合はEscを送らず、右クリックだけを行います。

**初回は画面の登録が必要です。** Minecraftでメニューを表示できる状態にし、ソフトの「3秒後にポーズメニューを登録」を押したら、3秒以内にMinecraftのゲーム画面へ戻ってEscでポーズメニューを表示してください。ポーズメニューを表示した状態で登録が成功したことを確認してから試してください。登録した画像はアプリ起動中だけ保持されます。解像度・MinecraftのGUIスケール・リソースパックのUIデザインを変更したときは登録し直してください。

メニュー判定は画面上部中央の「ゲームに戻る」ボタンの画像を比較する方式です。画面構成やUIの変更、カーソルによるボタンのハイライトなどにより、ポーズメニューが開いていても検出できない場合や、通常画面をメニューと誤認する場合があります。**ウィンドウ名や音声だけからメニューの開閉状態を正確に知ることはできません。** ポーズメニュー未登録時は安全のため自動でEscや右クリックを送信しません。シングルプレイで判定を確認してください。

## 4. 選択したSEを検出して自動実行する（試験的機能）

**自動検出は初期状態ではオフです。** 使用する場合のみ、まず上の「操作内容」と操作対象のMinecraftウィンドウを選びます。ブラウザ側からMinecraftに切り替えたい場合は「操作キーで選択したウィンドウに切り替えてから操作する」にチェックを入れます。

1. 「音声を選んでリソースパックを作成」で完成版ZIPを作成すると、作成に使用した元の音声が検出用にも選ばれます。別途指定する場合は「検出するMP3・WAV・OGGを選択」で**実際にリソースパックへ組み込んだ音声と同じ素材**を指定します。
2. Minecraftの音声出力が**Windowsの既定の再生デバイス**に設定されていることを確認します。「自動検出を開始」を押すとPCの再生音を監視し、類似した音が見つかった場合は手動キーと同じ操作を1回試みます。「自動検出を停止」を押すと監視を停止します。手動操作キーは自動監視とは別に使用できます。
3. 音声認識は**およそ0.70～1.36倍の再生速度、およそ±5半音のピッチ変化**を独立に試したパターン照合です。元の音声と完全一致させる方式ではありません。ただし大きな速度・ピッチ変化、効果音が短い場合、ほかの音が重なる場合やゲーム・PCの音量が小さい場合は検出に失敗する可能性があります。正確な認識や即時の入力を保証するものではありません。
4. 連続する類似音への反応を抑えるため、音声検出後は最低4秒の再実行防止時間があります。**このリソースパックの水しぶき音はウキの着水時にも鳴る場合があるため、魚が掛かった瞬間だけを区別できず、投入直後に意図せず右クリックする可能性があります。**メニュー画像も音声も一致判定に誤りがあり得るため、まずシングルプレイで**誤反応・検出遅延・釣り操作の順番**を確かめてください。

この方式はMinecraft内部の音声イベントを取得するものではなく、**Windowsの既定の再生デバイス全体のループバック音声**を照合します。そのため、ブラウザ、動画、通知などから似た音が鳴った場合にも誤反応し得ます。音声や画面画像はPC内で処理し、クラウドにアップロードしません。出力先が別のヘッドセットや仮想デバイスの場合は音を拾えません。音声の取得ができない場合はソフトの「音声監視エラー」を確認してください。

**マルチプレイサーバーで自動操作が許可されるとは限りません。** 使用先のルールを確認してください。規約上認められない自動操作や意図しない誤操作を避けるため、通常は自動検出を停止した状態で使用してください。

## 5. 好きなSE入りのリソースパックをアプリで作成する

**ZIPへの手動追加は不要です。** 新しいEXEの「音声を選んでリソースパックを作成」ボタンから、MP3・WAV・OGGを選び、**音量を1.0～5.0倍のバーで指定した音声入り**のMinecraft Java版26.2向け完成版リソースパックが作れます。

1. 最新のビルド済み `HalfAutoFishing.exe` を起動し、「音声を選んでリソースパックを作成」を押します。
2. 音量バーで1.0～5.0倍（0.1倍刻み、初期値3.0倍）を選び、好きなMP3・WAV・OGG音声ファイルを指定します。選んだ倍率で増幅し、ピークを抑えてOGG Vorbisに変換します。音量の設定は次回起動時にも引き継ぎます。
3. ZIPの保存先を選びます。初期ファイル名は `Fishing_SE_Custom_26_2.zip` です。変換中はしばらく操作せず、完成通知を確認します。
4. Windowsキー + R → `%APPDATA%\\.minecraft\\resourcepacks` を開き、生成されたZIPをそのまま入れます。**ZIPを展開したり、中に音声を追加したりする必要はありません。**
5. Minecraftの「設定 → リソースパック」で有効化します。反映されない場合はF3+Tで再読み込みします。非標準のゲームディレクトリを使用している場合はそのディレクトリ内の `resourcepacks` を使います。

作成したZIPには `pack.mcmeta`、`assets/minecraft/sounds.json`、`assets/minecraft/sounds/custom/fishing_alert.ogg` が含まれます。変換処理はPC内で完結し、元のMP3/WAV/OGGファイルは変更しません。音声は選択した1.0～5.0倍に増幅した上で、過大なピークをリミッターで抑えます。元音源が大音量の場合、リミッターが働くため実際の聴感上の音量が指定倍率になるとは限らず、音が圧縮される場合があります。再生音量には十分ご注意ください。変換用FFmpegはEXEに同梱するため別途インストール不要です。保存先に同名のZIPがある場合は上書きされるため、必要なファイルは別名で保存してください。

釣りの水しぶき音 `entity.fishing_bobber.splash` を置き換えます。**魚がかかったときだけでなく、ウキの着水時にも鳴る場合があります。** このリソースパックの音声をPC再生音から照合する自動機能はありますが、着水音とヒット音を確実に区別するものではありません。音が大きすぎる場合はMinecraftやPC側の設定、または元音声の音量を調整してください。

### 既存の空テンプレートZIPについて

GitHubの [釣りSE変更パック ZIP テンプレート](resourcepack/Fishing_SE_26_2_Template.zip) は手動で音声を追加する旧方式です。**新しいEXEで完成版ZIPを生成する場合はテンプレートのダウンロードも編集も必要ありません。**

## 6. ソースから動かす・EXEを自作する

Python 3.12をインストールして、このリポジトリをダウンロードし、フォルダ内で以下を実行します。

```powershell
py -m pip install -r requirements.txt
py src/fishing_app.py
```

EXEをローカルで作る場合：

```powershell
py -m pip install -r requirements.txt pyinstaller
py -m PyInstaller --noconfirm --clean --onefile --windowed --collect-all imageio_ffmpeg --collect-all soundcard --collect-all scipy --name HalfAutoFishing src/fishing_app.py
```

完成品は `dist/HalfAutoFishing.exe` です。GitHubの **Actions → Windows EXE build → Run workflow** からもビルドできます。push時にも自動ビルドします。

## 7. モジュール不足の解決（Windows・コピペ用）

**先に、起動したものが `HalfAutoFishing.exe` か、ソースコードの `src/fishing_app.py` か確認してください。対処方法が異なります。**

### A. Pythonでソースを実行している場合

Windowsの**PowerShell**を開き、GitHubから取得したプロジェクトフォルダ（`requirements.txt` がある場所）で、次のコマンドを**1行ずつ**実行してください。

```powershell
py -3.12 -m pip install --upgrade pip
py -3.12 -m pip install -r requirements.txt
py -3.12 src/fishing_app.py
```

`requirements.txt` が見つからない場合は、PowerShellでプロジェクトフォルダに移動してから実行してください。たとえばダウンロードしたZIPをデスクトップの `Half_Auto_Fishing-Minecraft` フォルダに展開した場合は、以下のように移動します（実際の保存先に合わせて変更してください）。

```powershell
cd "$env:USERPROFILE\Desktop\Half_Auto_Fishing-Minecraft"
```

`py -3.12` が見つからない場合はPython 3.12をインストールしてください。既にPython 3.12が起動できる場合は、同じPythonの `python -m pip` を使ってください。

**`requirements.txt` を使わずに必要モジュールを一括インストールする場合のコピペ用コマンド**（WindowsのPython 3.12向け）：

```powershell
py -3.12 -m pip install "keyboard>=0.13.5,<1" "PyAutoGUI>=0.9.54,<1" "imageio-ffmpeg>=0.6.0,<1" "numpy>=1.26,<3" "scipy>=1.14,<2" "soundcard>=0.4.5,<1"
```

Pythonの標準機能である `tkinter`、`ctypes`、`json` などは通常pipで追加インストールする必要はありません。

### B. GitHub ActionsからダウンロードしたEXEで「No module named ...」が出る場合

**EXEは必要なPythonライブラリを同梱する形式です。上のpipコマンドを実行しても、EXE内のモジュール不足は通常解決しません。** 以前のEXEで表示された `No module named 'PIL'` は、画像処理用Pillowの同梱漏れが原因でした。Pillowを依存関係に追加し、最新版のビルドで明示的に同梱するよう修正しています。 まず最新の成功済み [Windows EXE build](../../actions/workflows/windows-build.yml) のArtifactsから`HalfAutoFishing-Windows`を再ダウンロードし、ZIPを展開して**古いEXEを終了してから**入れ替えてください。以前のEXEを間違えて起動していないか、保存場所も確認してください。

最新版EXEでも同じエラーが出るときは、エラーメッセージに表示された**モジュール名（`No module named '...' `）の全文と、実行履歴のリンク**を共有してください。EXEのビルド設定で同梱漏れや互換性の問題を調査する必要があります。DLL読み込みエラーやWindowsセキュリティ機能によるファイル隔離が原因の場合もあり、その際は正確なエラー文が必要です。出所が確認できないDLLを別サイトからダウンロードして配置することは避けてください。

## 8. トラブル対応

- **途中から操作できなくなった：** キーの受信表示がないときは「キー検知を再登録」を押してください。受信表示があるときは画面切り替えのエラーを確認してください。ゲームを再起動した場合は「停止」→「再検索」→ゲーム画面を再選択→「保存して開始」をお試しください。ウィンドウ切替に失敗した場合はアプリ画面の状態メッセージも確認してください。\n- **F8で動かない：** 「保存して開始」を押したか確認し、「別の画面からMinecraftへ切り替えて操作する」をオンにする。Minecraftが見つからない場合はゲーム本体を起動して「再検索」でゲームウィンドウを選択する。前面化に失敗する場合はウィンドウモードで試す。管理者権限が異なる場合やゲーム側の入力処理により反映されない場合があります。
- **Escでメニューが開く：** 「右クリックのみ」に戻す。メニューが開いていると釣り竿を操作できません。
- **キーが連続で反応しない：** 連続実行防止時間が経過してから押す。
- **設定を初期化したい：** アプリを終了し、`%APPDATA%\HalfAutoFishing\config.json` を削除して再起動する。
- **WinError 17（別のディスクドライブへ移動できない）：** 旧EXEの保存処理の不具合です。最新版EXEに更新すると、CドライブからDドライブなど別ドライブへの保存にも対応します。古いEXEでは一時的にCドライブへ保存してから手動で移動してください。\n- **音声の変換に失敗する：** ファイルがMP3/WAV/OGGか確認する。壊れた音声や音声トラックがないファイルには対応していません。保存先の権限や空き容量も確認してください。\n- **ZIPを導入しても音が変わらない：** 作成したZIPをresourcepacks直下に置き、有効化する。別のリソースパックで同じサウンドが上書きされていないか確認してください。\n- **EXEが見つからない：** Actionsのビルドが成功しているか確認する。成果物はリポジトリのソース一覧ではなく実行履歴のArtifacts内にあります。
- **動作時にエラーが出る：** Python版をコマンドプロンプトから実行し、表示されるエラーを確認してください。

## 9. 更新・保守

ソース変更後、GitHubのmainブランチにpushするとActionsでWindows用EXEを再生成します。新しい実行履歴のArtifactsから再ダウンロードして旧EXEと交換してください。ユーザー設定はAPPDATAに残ります。変更の前後にシングルプレイでキー操作・停止・Minecraft以外での誤操作防止を確認してください。
