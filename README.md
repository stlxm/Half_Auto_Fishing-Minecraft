# Minecraft 半自動釣り（Windows 11）

Minecraft Java版で釣りのヒット音を**自分で聞き、操作キーを押した場合にだけ**入力を1回送るGUIアプリです。魚の自動検知・完全自動釣り・マクロ検知回避機能はありません。使用するサーバーのルールを確認してください。

## 1. ダウンロードと起動（Python不要）

1. このリポジトリの **Actions** タブを開く。
2. 左の **Windows EXE build** → 一番新しい成功済みの実行履歴を開く。
3. ページ下の **Artifacts** にある `HalfAutoFishing-Windows` をダウンロードする（GitHubへのログインが必要な場合があります）。
4. ZIPを展開して `HalfAutoFishing.exe` を取り出す。
5. EXEをダブルクリックして起動する。コマンドプロンプトは不要です。

※ **Actionsが成功するまではEXEをダウンロードできません。** Windows向けビルドはGitHub Actions上で行います。公開された実行ファイルを使う場合、出所を確認してから実行してください。SmartScreenが警告する場合があります。無条件で警告を回避せず、入手元とファイルを確認してください。

## 2. 初回設定と使い方

1. Minecraftを起動する。最初に自分のシングルプレイワールドで動作を確認する。
2. `HalfAutoFishing.exe` を起動し、操作キー（初期値F8）を選ぶ。
3. 「操作内容」は通常「右クリックのみ」を選ぶ。Escを押すとMinecraftのメニューが開くため、「Esc → 右クリック」は独自UI等で必要な場合だけ選ぶ。「Esc → Esc → 右クリック」も選択できます。
4. 操作間隔（初期値120ms）と連続実行防止（初期値500ms）を必要に応じて指定する。
5. 「別の画面からMinecraftへ切り替えて操作する」をオンにすると、ブラウザなど別の画面を開いていても操作キーを押した際にMinecraftを前面にしてから操作します。「Minecraftが前面にある場合だけ実行する」もオンを推奨します。
6. 「保存して開始」を押す。別のアプリを開いていても、魚がかかった音を**自分で確認して**指定キーを1回押すと、Minecraftを前面に切り替えてから指定操作を1回実行します。
7. 終わったらアプリ画面で「停止」を押すか、アプリを閉じる。

キーの設定を変える場合は一度「停止」してから設定を変え、「保存して開始」を押してください。設定は `%APPDATA%\HalfAutoFishing\config.json` に保存され、次回起動時にも読み込まれます。

### 別の画面からの操作について

- 初期設定では「別の画面からMinecraftへ切り替えて操作する」がオンです。オフにすると従来どおりMinecraftが前面の場合にのみ操作します。
- 操作キーを押すと**実際に画面がMinecraftへ切り替わります**。ほかのアプリを開いたまま裏側のMinecraftだけを操作する機能ではありません。作業中の入力やマウス操作が中断される場合があります。
- Minecraftのゲームウィンドウが見つからない、またはWindowsが前面化を拒否したときは、ほかのアプリへの誤入力を避けるため何も送信しません。
- Minecraftのウィンドウモード／ボーダーレスで先に確認してください。全画面時や権限の異なるアプリの前面化は環境によって成功しない場合があります。
- **Esc → 右クリック** を選んでも、Escでゲームメニューが開いた場合は釣り竿の操作にはなりません。その場合は「右クリックのみ」、または必要に応じて「Esc → Esc → 右クリック」を試してください。

## 3. 釣りSE変更リソースパック（Minecraft Java版26.2）

GitHub内の [釣りSE変更パック ZIP テンプレート](resourcepack/Fishing_SE_26_2_Template.zip) をダウンロードできます（GitHubのファイル画面で **Download raw file** を押してください）。

**重要：GitHub版ZIPはご自身の効果音を入れるためのテンプレートで、音声ファイルは未同梱です。音声を入れない状態では釣りのSEは鳴りません。**

1. 任意の音声を **OGG Vorbis形式** に変換し、`fishing_alert.ogg` というファイル名にします。拡張子だけ変更しても変換にはなりません。
2. ZIPを開き、`assets/minecraft/sounds/custom/` に `fishing_alert.ogg` を追加します。元のフォルダ階層を維持してください。
3. Windowsキー + R → `%APPDATA%\\.minecraft\\resourcepacks` を開き、音声を追加したZIPをコピーします。
4. Minecraftの「設定 → リソースパック」で有効にします。反映されない場合はF3+Tで再読み込みします。

釣りの水しぶき音 `entity.fishing_bobber.splash` を置き換えます。**魚がかかった時だけでなく、着水時にも鳴る場合があります。** 正確なヒット検出は行いません。対象ゲームバージョンでパック形式が変更された際には適宜更新が必要です。

## 4. ソースから動かす・EXEを自作する

Python 3.12をインストールして、このリポジトリをダウンロードし、フォルダ内で以下を実行します。

```powershell
py -m pip install -r requirements.txt
py src/fishing_app.py
```

EXEをローカルで作る場合：

```powershell
py -m pip install -r requirements.txt pyinstaller
py -m PyInstaller --noconfirm --clean --onefile --windowed --name HalfAutoFishing src/fishing_app.py
```

完成品は `dist/HalfAutoFishing.exe` です。GitHubの **Actions → Windows EXE build → Run workflow** からもビルドできます。push時にも自動ビルドします。

## 5. トラブル対応

- **F8で動かない：** 「保存して開始」を押したか確認し、「別の画面からMinecraftへ切り替えて操作する」をオンにする。Minecraftが見つからない場合はゲーム本体を起動する。前面化に失敗する場合はウィンドウモードで試す。管理者権限が異なる場合やゲーム側の入力処理により反映されない場合があります。
- **Escでメニューが開く：** 「右クリックのみ」に戻す。メニューが開いていると釣り竿を操作できません。
- **キーが連続で反応しない：** 連続実行防止時間が経過してから押す。
- **設定を初期化したい：** アプリを終了し、`%APPDATA%\HalfAutoFishing\config.json` を削除して再起動する。
- **EXEが見つからない：** Actionsのビルドが成功しているか確認する。成果物はリポジトリのソース一覧ではなく実行履歴のArtifacts内にあります。
- **動作時にエラーが出る：** Python版をコマンドプロンプトから実行し、表示されるエラーを確認してください。

## 6. 更新・保守

ソース変更後、GitHubのmainブランチにpushするとActionsでWindows用EXEを再生成します。新しい実行履歴のArtifactsから再ダウンロードして旧EXEと交換してください。ユーザー設定はAPPDATAに残ります。変更の前後にシングルプレイでキー操作・停止・Minecraft以外での誤操作防止を確認してください。

## 注意

第三者のマルチサーバーでは手動起動のマクロも禁止される場合があります。検知回避や不正な自動化を保証するものではありません。
